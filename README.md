# Kampung Kecil Cirebon — Multi Page Premium Demo

Halaman:
- `index.html` — Beranda
- `cerita.html` — Cerita Kami
- `menu.html` — Menu
- `suasana.html` — Galeri Suasana
- `kunjungi.html` — Alamat, jam, WhatsApp, dan Maps

Background music memakai `assets/musik.mp3`, loop otomatis, volume 32%, tanpa tombol musik. Browser yang memblokir autoplay akan memulai musik pada interaksi pertama (tap/scroll/keyboard).

Catatan: item menu dibuat sebagai struktur demo dan perlu diganti dengan daftar/harga resmi cabang Cirebon sebelum dipublikasikan.
