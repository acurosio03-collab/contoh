# WebCraft Premium — Ready-to-Sell Template

Landing page premium dengan identitas "ticket/stamp studio":
- Hero berupa tumpukan kinetic typography (ticker text bertumpuk) dengan satu kata "distempel" — bukan pola template teks-kiri/objek-kanan.
- Section Services memakai kartu bergaya tiket sobek yang tersebar & sedikit rotate, bukan grid 2 kolom rata.
- Section Process memakai staircase (tangga menurun) yang benar-benar merepresentasikan urutan tahapan.
- CTA kontak berupa "stempel" berputar (teks melingkar SVG) menggantikan tombol link biasa.
- Typography oversized (Unbounded untuk display, Space Grotesk untuk struktur, DM Sans untuk body).
- Grain overlay, tape-strip ticker, custom cursor desktop, hover interactions.
- Responsive mobile/tablet/desktop.
- Sections: Work, Services, Process, Contact.
